Gallery is a private, open-source photo and video gallery maintained independently as BaizhuGallery by baizhu945.

Browse and organize local photos and videos, edit images, customize the interface, and recover recently deleted media from the recycle bin. No ads.

Based on Fossify Gallery, with thanks to its contributors and earlier upstream contributors. This project is independently maintained and is not an official Fossify release. It uses the separate application ID org.fossifymigration.baizhu.gallery.

Source and releases: https://github.com/baizhu945/BaizhuGallery
Bugs and feature requests: https://github.com/baizhu945/BaizhuGallery/issues
Questions: https://github.com/baizhu945/BaizhuGallery/discussions
Please report this project's issues here, not to the upstream project.
