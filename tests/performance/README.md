# Isolated production-helper performance checks

Run `bash tests/performance/run.sh` from any working directory with existing `kotlinc`, Java, Git and Python 3. No Gradle/dependencies/build changes. Do not run compilation while the emulator frame benchmark is active.

Outputs default to `~/.cache/gallery-performance/benchmark/pure/` (`GALLERY_BENCH_OUT` overrides). Baseline helper files are extracted with `git show 79acc:...`; current production helpers are copied without editing app source. The same deterministic 2,000/20,000-image paths and 500/2,000 registered roots run 3 JVM warmups + 5 timed samples. Timings exclude registry/path construction; counters are actual injected probe/originalPath callbacks, not real filesystem IO latency. Median summaries are in JSON, raw samples CSV. Current-only media queries separately exercise `matchesMedia` filename-probe avoidance; compare baseline general queries explicitly, not as identical APIs.

9 helper algorithm assertions run for both source versions, including prefix boundaries, deepest roots, independent hidden descendants and mapped hidden paths. Existing hidden-media-filter suite also runs unchanged. Selection checks compile the exact `AdapterRowIndex` class extracted from its mixed Android source file; no RecyclerView stub or Android behavior claim. `dispatchRowChanges` is not tested.

UI harness, deterministic fixture generator, preference snapshot, APK verification, raw frame stats and baseline report are in `~/.cache/gallery-performance/benchmark/`. All adb invocations explicitly target emulator-5590. The measured replacement candidate is `f98630be4a0a0532a3f5ef435f54397d4d0c31c1e45a7bac08ce19bb5c0587ae`; all 12 candidate samples completed. `REPORT.md` and `comparison.json` include measured regressions as well as improvements. Future APKs must be hash-verified with `install_verified.py` before running `ui_bench.py` with a fresh result label. Keep the same emulator volume/fixture and theme/density/font; do not clear app data, uninstall or regenerate the fixture between APKs.
